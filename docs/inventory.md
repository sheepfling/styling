# Source and publication inventory

This public repository contains six neutral profile slots and synthetic
tooling fixtures. It does not identify or summarize the private systems that
may use the shared exporter.

## Public inventory

| Source class | Public state | Publication gate |
| --- | --- | --- |
| Profile identity | Six generic slots in `profiles/registry.json`; each is source-review-pending. | Record an exact source, rights, and approved direction before adding identity data. |
| Marks and artwork | Synthetic starter mark only. | Obtain publication clearance for any source-specific identity or illustration. |
| Fonts | No source-family font binaries are included in the public profiles. | Verify font identity, license, and redistribution terms before bundling. |
| Output proofs | One synthetic starter PDF/SVG example; no source-family proofs. | Pin source and output hashes, render the pages, and record the output status. |
| Web behavior | Static checks are part of the shared exporter. | Browser behavior must be recorded separately for each source profile. |

Local source work may use this shared contract without publishing its source
files. A public family package requires explicit publication clearance and
evidence for each claimed output. A passing contract test does not grant rights
to artwork, fonts, claims, or proof files.
